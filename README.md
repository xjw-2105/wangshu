# THE ARCHIVE OF TRADITION

A 72-second real-time architectural film for a presentation on tradition as a method.

## Publish on GitHub Pages

1. Sign in to GitHub and create a new **public** repository.
2. Upload these five files directly into the repository:
   - `index.html`
   - `preview.png`
   - `README.md`
   - `CREDITS.md`
   - `.nojekyll`
3. Open the repository's **Settings**.
4. Choose **Pages** in the left sidebar.
5. Under **Build and deployment**, choose **Deploy from a branch**.
6. Select the `main` branch and the `/ (root)` folder, then click **Save**.
7. Wait for GitHub to show the published address, then open it in Chrome or Safari.

No installation, build command, server, account key, or external asset is required.

## Present

Open the published page, click **ENTER THE ARCHIVE**, and let the film play. The page requests fullscreen; if the browser declines, playback continues normally.

## Keyboard controls

- `Space` — pause / resume
- `1` — jump to Wang Shu
- `2` — jump to Liu Jiakun
- `3` — jump to I. M. Pei
- `4` — jump to the final reveal
- `R` — replay from the beginning
- `F` — enter / exit fullscreen
- `M` — mute / unmute

## Common questions

**There is no sound.** Click `SOUND OFF` in the top-right corner or press `M`. Browsers require a click before sound can start.

**Fullscreen did not open.** Press `F`; the film itself works without fullscreen.

**Motion feels too strong.** Enable “Reduce motion” in the operating system, or append `?motion=reduced` to the page address.

**The page is blank.** Refresh once in an up-to-date Chrome or Safari browser. If WebGL is unavailable, the page automatically uses a simpler 2D visual sequence.
